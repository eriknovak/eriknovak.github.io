## Prose & inline formatting

You get standard CommonMark + GFM: **bold**, _italic_, `inline code`,
[external links](https://www.tufte-css.com/), and ~~strikethrough~~. Smart
quotes and dashes are auto-converted, so writing "double quotes" and
em --- dashes --- produces typographic punctuation without any escaping.

Lists work as expected:

- Bullet item one
- Bullet item two with a `code span` inside
- Bullet item three

1. Numbered item one
2. Numbered item two
3. Numbered item three

> Block quotes get an accent left-rule and an italic muted treatment, useful
> for pulling out a phrase from a paper or interview.

## Sidenotes & margin notes

The body column is narrow on purpose; the right margin holds sidenotes
alongside the paragraph that references them.<Sidenote>Sidenotes are
numbered automatically — you do not pick the number.</Sidenote> Margin notes
are the same primitive without the number, useful when the aside does not
need a numeric reference.<MarginNote>Like this one — handy for tangential
context.</MarginNote>

A second paragraph with another sidenote to show that successive asides
stack vertically rather than overlap.<Sidenote>They queue down the gutter
in reading order, with `clear: right` between each.</Sidenote>

## Math

Inline math keeps flow: the softmax weights $w_i = e^{x_i} / \sum_j e^{x_j}$
sum to one. Display math needs the `$$` markers on their **own lines** —
single-line `$$...$$` is parsed as inline by `remark-math`:

$$
\mathcal{L} = -\sum_{i=1}^{N} \bigl[y_i \log \hat{y}_i + (1 - y_i) \log (1 - \hat{y}_i)\bigr].
$$

### Referencing equations

Drop an `<a id="eq-…">` anchor before the equation, optionally use KaTeX's
`\tag{}` to render a visible label, then reference it from anywhere in the
post with a normal markdown link.

$$
\mathcal{L}_{\mathrm{CE}} = -\sum_i y_i \log \hat{y}_i \tag{1}
$$

## Code

Fenced code blocks are highlighted by Shiki with a dark/light dual theme
that follows the site theme.

```python
import numpy as np

def softmax(x: np.ndarray) -> np.ndarray:
    """Stable softmax — subtracts the max for numerical safety."""
    e = np.exp(x - x.max())
    return e / e.sum()
```

Inline code spans like `np.exp(...)` look like this in body text.

## Headings & cross-references

Every heading gets an auto-generated anchor id (`## Foo bar` → `#foo-bar`),
which means you can link back to any section with a plain markdown link:
[jump to Citations](#citations) or [jump to the equation](#eq-loss). Hover a
heading on desktop to see the anchor link icon.

## Optional sticky TOC

Adding a `toc:` array to the frontmatter renders a sticky left-margin
table of contents on screens ≥1100px. Each entry maps `id` (the heading
anchor) to `t` (display title):

```yaml
toc:
  - { id: "math", t: "Math" }
  - { id: "code", t: "Code" }
  - { id: "citations", t: "Citations" }
```

Below 1100px the TOC collapses inline above the article.
