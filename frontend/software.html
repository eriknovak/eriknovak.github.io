Software

Services

InfoMiner nodejs

InfoMiner is an semi-automatic exploration tool. It enables the user to create topic ontologies by clustering, labelling and querying textual documents.

Check it out: https://github.com/eriknovak/infominer-public

Text Embedding Service python

A service for producing text representations via word embeddings.

Check it out: https://github.com/eriknovak/text-embedding-service

Document Enrichment Tool nodejs

The tool is intended to enrich text/documents by extracting the content, and providing various annotations and labels to it. The service is based on the qtopology module, which is a distributed stream processing layer and is able to construct components for adding them to the tool.

Check it out: https://github.com/eriknovak/document-enrichment-tool
